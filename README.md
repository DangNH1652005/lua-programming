# Lua Programming

My journey of learning **Lua**, from basic syntax and data types to recursion and other programming concepts.

This repository contains simple examples and practice code written while learning Lua.

## 📚 Topics

| File | Description |
|---|---|
| `base.lua` | Basic Lua syntax and fundamentals |
| `hello.lua` | Hello World and the first Lua program |
| `recursion.lua` | Understanding recursion with Lua |
| `variable-and-data-types.lua` | Variables and data types in Lua |

## 🚀 Getting Started

### Install Lua

On NixOS, you can temporarily use Lua through the Nix package environment:

```bash
nix shell nixpkgs#lua
```

### Run a Lua program

For example:

```bash
lua hello.lua
```

Run any other example using the same approach:

```bash
lua base.lua
lua recursion.lua
lua variable-and-data-types.lua
```

## 🎯 Goals

- Learn Lua syntax and fundamentals.
- Understand variables, data types, and control flow.
- Practice functions and recursion.
- Build a solid foundation for writing Lua programs.
